# ReqPOOL Estimation Manager

Einfache Onlineplattform als Single-Page-Webanwendung zur **parametrisierten Aufwandsschätzung** und **Scope-Beschreibung**.

## Input-Parameter
- Pages
- Use Cases
- Business Objects
- Interfaces
- Batches
- Languages
- Roles
- User
- Kurze Projektskizze

## Output
- Parametrisierte Aufwandsschätzung (Basisaufwand, Risikofaktor, Gesamtaufwand, Teamgröße, Dauer)
- Scope-Beschreibung auf der Ergebnisseite
- PDF-Export via Browser-Print (`Als PDF speichern`)

## Start
Öffne `index.html` direkt im Browser.
