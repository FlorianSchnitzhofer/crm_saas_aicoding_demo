# ReqPOOL Estimation Manager

Einfache Onlineplattform (Single-Page-App) zur parametrisierten Aufwandsschätzung und Scope-Beschreibung.

## Start

Öffne `index.html` im Browser oder starte lokal einen Webserver, z. B.:

```bash
python3 -m http.server 8080
```

Danach: `http://localhost:8080`

## Eingaben

- Pages
- Use Cases
- Business Objects
- Interfaces
- Batches
- Languages
- Roles
- User
- kurze Projektskizze

## Ausgabe

- Parametrisierte Aufwandsschätzung in Personentagen (PT)
- Scope-Beschreibung auf der Seite
- Download als PDF-Dokument
