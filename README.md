# CRM SaaS AI Coding Demo\n\nA complete Pipedrive-like CRM system built with Node.js, Express, React, and PostgreSQL.\n\n## Project Structure\n\n- **/backend**: Node.js/Express server\n  - **/config**: Configuration files\n  - **/controllers**: API Controllers\n  - **/models**: Database models\n  - **/routes**: API routes\n  - **/migrations**: Database migrations\n  - **/middleware**: Authentication middleware\n  - **server.js**: Entry point for the server\n- **/frontend**: React application\n  - **/src/components**: React components\n  - **/src/pages**: Page components\n  - **/src/utils**: Utility functions\n  - **/src/styles**: Tailwind CSS configuration\n  - **/public**: Public files\n- **.env.example**: Environment example file\n- **README.md**: Documentation file\n- **package.json**: Node dependencies for backend and frontend\n\n## API Routes\n\n- **Contacts**: CRUD operations for contacts.\n- **Companies**: CRUD operations for companies.\n- **Deals**: CRUD operations for deals.\n- **Activities**: CRUD operations for activities.\n- **Authentication**: User login/register.\n\n## Database Schema (PostgreSQL)\n1. **Users** table\n2. **Contacts** table\n3. **Companies** table\n4. **Deals** table\n5. **Activities** table\n\n## Configuration Files\n- Setup for PostgreSQL, JWT authentication.\n\n## Environment Examples\n- Create a `.env.example` file with placeholders for sensitive information.
